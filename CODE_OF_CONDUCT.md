# Code of Conduct

## Our Pledge

We are committed to providing a welcoming, respectful, and inclusive environment for everyone.

## Expected Behavior

* Be respectful and professional.
* Welcome feedback and collaboration.
* Support constructive discussions.
* Help improve the project for everyone.

## Unacceptable Behavior

* Harassment or discrimination.
* Offensive language or personal attacks.
* Sharing confidential information without permission.
* Any behavior that negatively affects the community.

## Enforcement

Project maintainers may remove inappropriate content or restrict contributions that violate this Code of Conduct.
