# AGENTS.md

## Project

**LocalSeek AI – Offline Document Intelligence**

## Purpose

This project provides offline document processing, OCR, metadata extraction using Ollama (Llama 3.2), local indexing, and document search.

## AI Components

* Ollama
* Llama 3.2
* OCR (Tesseract)
* SQLite Database

## Responsibilities

### Frontend

* User Interface
* File Upload
* Search Interface
* Dashboard

### Backend

* PDF Processing
* OCR
* Metadata Extraction
* Database Indexing
* Search Engine
