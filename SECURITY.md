# Security Policy

## Supported Versions

The latest version of LocalSeek AI is actively maintained and receives security updates.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it by creating a private issue or contacting the project maintainers.

Please include:

* Description of the vulnerability
* Steps to reproduce
* Expected and actual behavior
* Screenshots or logs (if applicable)

We will review and address valid security reports as soon as possible.

## Security Best Practices

* Do not upload confidential documents unless you trust the environment.
* Keep Python packages updated.
* Use the latest version of Ollama and Llama 3.2.
* Avoid exposing local databases publicly.
* Protect API keys if cloud services are added in the future.
